## 准备手机

1. 打开「设置 → 关于手机」，连续点击「版本号」7 次，开启开发者选项；
2. 进入「开发者选项」，打开 **USB 调试**；
3. 用数据线连接电脑，手机弹出「允许 USB 调试吗？」时勾选「始终允许」并确定。

> 若之前误点了「拒绝」，请在开发者选项中执行「撤销 USB 调试授权」后重试。

## USB 投屏

1. 连接数据线，SmartCast 会自动扫描（默认每 2 秒）；
2. 首页「设备概览」出现设备小卡片；
3. 点卡片上的「**开始投屏**」；
4. 投屏窗口出现后，窗口下方会显示悬浮控制条。

## Wi-Fi 投屏

### 第一步：让手机开启 ADB 网络调试

**方式 A（最通用）**
1. 先用 USB 连接手机；
2. 在电脑执行 `adb tcpip 5555`（可用 SmartCast 内置 ADB：`resources\adb\adb.exe tcpip 5555`）；
3. 拔掉数据线。

**方式 B（Android 11+）**
开发者选项 →「无线调试」→ 开启，并记下显示的 IP 与**端口**（端口每次可能不同）。

### 第二步：在 SmartCast 中连接

1. 进入「设备管理」页；
2. 点右上角「**网络连接设备**」；
3. 输入地址：
   - 完整地址：`192.168.1.23:5555`
   - 或只填 IP，端口单独填（默认 5555）
4. 点「**连接设备**」。

也可以用「**扫描局域网**」：自动探测本机 /24 子网的 5555–5560 端口，并直连历史连接过的地址。

### 第三步：投屏

连接成功后，设备卡片会显示 **Wi-Fi** 标识，点「开始投屏」即可。

> 连接成功的判定很严格：`adb connect` 返回成功后会再检查 `adb devices` 状态并执行一次 shell 探活，全部通过才算成功。

### 断开 Wi-Fi 设备

在设备卡片上点「**断开**」，或在连接窗口里点「断开连接」——只会断开这一台 `IP:PORT`，不影响其他设备。

## 首页与设备管理

### 首页

| 区域 | 说明 |
|---|---|
| 设备概览 | 每台设备一张竖版小卡片，显示连接类型与状态，可直接开始投屏 |
| 手机控制 | 返回 / 主页 / 多任务 / 音量 / 静音 / 锁屏 / 电源菜单 |
| 屏幕控制 | 亮度、旋转、常亮、恢复，以及熄屏投屏 / 全屏 / 截图 / 录屏 |
| 运行概况 | ADB 服务、在线设备、投屏中、最近扫描 |
| 常用操作 | 立即扫描、设备管理、投屏配置、连接帮助 |

> 手机控制与屏幕控制作用于**当前主设备**（设备概览中第一台在线设备）。多设备时可在设备管理页切换到具体设备。

### 设备管理

- 展示所有已连接设备卡片（USB / Wi-Fi 标识、状态、编码器信息）；
- 每张卡片可：开始/停止投屏、查看详情、设备设置、复制序列号、断开 Wi-Fi 连接；
- 「网络连接设备」入口在此页右上角。

## 手机控制

| 按钮 | 效果 |
|---|---|
| 返回 | 系统返回键（keyevent 4） |
| 主页 | 回到桌面（keyevent 3） |
| 多任务 | 最近任务（keyevent 187） |
| 音量 + / − | 音量加减（keyevent 24 / 25） |
| 静音 | 静音切换（keyevent 164） |
| 锁屏 | 电源键（keyevent 26），亮屏时按下即熄屏锁定 |
| 电源菜单 | 长按电源键，调出系统电源选项 |
| 唤醒 | 唤醒屏幕（keyevent 224） |

> 电源菜单 / 锁屏可能导致熄屏，界面上已标注提醒。
> 所有命令都带 `-s <serial>`，多设备不会串台。

## 屏幕控制

| 功能 | ADB 实现 | 是否记录原值 |
|---|---|---|
| 亮度滑块 | `settings put system screen_brightness` | ✅ |
| 自动亮度 | `settings put system screen_brightness_mode` | ✅ |
| 自动旋转 / 竖屏 / 横屏 | `accelerometer_rotation` + `user_rotation` | ✅ |
| 屏幕常亮 | `screen_off_timeout = 2147483647` | ✅ |
| 恢复原始亮度 | 一次性还原全部已记录项 | — |
| 恢复休眠时间 | 还原 `screen_off_timeout` | — |

原始值按设备保存在 `config/devices.json` 的 `screen_backup` 字段中，**重启软件不会丢失**。

部分 Android 11+ 机型由厂商策略保护亮度设置，此时会提示失败（系统限制，非软件问题）。

## 投屏中心

- 列出当前所有投屏会话；
- 显示：设备名、USB / Wi-Fi、状态、**实时运行时长**、编码器 / 码率 / 分辨率 / 帧率；
- 每个会话可独立「全屏」或「停止」，互不影响；
- 会话状态与设备在线状态分离：设备离线时显示「设备离线」，但进程可能仍在。

## 截图与录屏

### 截图

- 触发方式：首页「屏幕控制」→「截图」，或悬浮控制条「截图」；
- 实现：`adb exec-out screencap -p` 直接读取 PNG 字节流；
- 保存：`<用户数据目录>/SmartCast/screenshots/<设备型号>/`。

### 录屏

- 触发方式：首页「屏幕控制」→「开始录屏」，或悬浮控制条「录屏」；
- 实现：启动 `scrcpy --no-window --record <file> --no-audio`；
- 再次点击「停止录屏」结束并保存；
- 保存：`<用户数据目录>/SmartCast/recordings/<设备型号>/`。

> 录屏为**无声**录制。scrcpy 不支持在已有投屏会话中动态开启录制，因此采用独立进程方案，不会产生第二个投屏窗口。

### 媒体管理

侧边栏「媒体管理」：

- 按设备、按类型（截图 / 录屏）筛选；
- 打开文件、打开所在目录；
- **删除记录**（只删历史，保留文件）；
- **删除文件**（二次确认，删文件并删记录）；
- 文件被外部删除时标记为「缺失」，不会异常。

## 自定义背景

每个功能页面都可以放一张自己的插画作为背景。

1. 准备图片（建议 16:9 横图，宽度 1600px 以上，小于 5MB）；
2. 重命名为 `background.png`；
3. 放到对应目录：

```
resources/assets/illustrations/home/background.png       首页
resources/assets/illustrations/devices/background.png    设备管理
resources/assets/illustrations/casting/background.png    投屏中心
resources/assets/illustrations/control/background.png    设备控制
resources/assets/illustrations/media/background.png      媒体管理
resources/assets/illustrations/settings/background.png   设置
resources/assets/illustrations/logs/background.png       运行日志
```

4. 重启 SmartCast，切换页面即可看到对应背景。

**说明**

- 图片不存在或损坏时，页面自动使用纯色背景，不影响使用；
- 不同页面默认使用不同展示方式（右侧装饰 / 全区域 / 水印），避免遮挡内容；
- 功能面板为半透明白色，插画会自然透出，文字保持清晰；
- 想统一调整透明度或展示方式，可编辑 `settings.json`：

```json
{
  "background_enabled": true,
  "background_opacity": 0.8,
  "background_mode": "",
  "background_position": ""
}
```

`background_mode` 可选 `fill` / `right` / `watermark`，留空表示使用各页面默认值；
`background_position` 可选 `left` / `center` / `right`，留空同样使用默认值。

## 设置

- **工具路径**：ADB / scrcpy 可执行文件路径（留空使用内置）；
- **扫描**：空闲扫描间隔、投屏时扫描间隔、自动扫描开关；
- **默认投屏参数**：编码、分辨率、帧率、码率、音频；
- **渲染后端**：OpenGL / auto / Direct3D / software；
- **主题**：浅色。

设备级参数在设备卡片「设置」中单独保存，优先级高于默认值。

## 故障排查

| 现象 | 排查方向 |
|---|---|
| 扫描不到设备 | 数据线是否支持传输、USB 调试是否开启、授权弹窗是否点允许 |
| 显示「未授权」 | 撤销 USB 调试授权后重连 |
| 显示「offline」 | 换线 / 重插 / 重启 ADB Server |
| Wi-Fi 连接超时（10060） | 是否同一网段、手机是否休眠、防火墙 |
| Wi-Fi 连接被拒绝（10061） | 手机 ADB 网络调试未开启或端口错误 |
| 连接失败（10013） | 端口被占用或防火墙拦截 |
| 投屏黑屏 | 尝试切换渲染后端（设置 → 渲染）；确认编码器可用 |
| 亮度改不了 | 厂商 ROM 限制，属系统级保护 |
| 控制条不出现 | 需投屏会话处于运行状态；Windows 平台专属功能 |

### 查看日志

侧边栏「日志」可实时查看运行日志，支持清空与导出。日志同时写入 `logs/smartcast.log`。
